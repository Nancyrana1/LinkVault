# LinkVault Privacy Policy

Last updated: November 23, 2026

LinkVault is a browser extension for saving, copying, and autofilling profile URLs.

## Information stored

LinkVault stores profile information that you enter, including profile names, HTTP or HTTPS URLs, and optional aliases. This information is stored locally using the browser's `chrome.storage.local` API.

## How information is used

Saved information is used to display your profiles, copy selected URLs, compare a webpage field's identifying text with your saved profile names and aliases, and fill a field only after you select a LinkVault suggestion.

## Data sharing and transmission

The LinkVault extension code does not include a backend service or code that sends saved profile information to a remote server. The extension does not sell or share saved profile information.

## Passwords and form submission

LinkVault does not store passwords and does not submit forms. A URL is inserted into a field only after you select the corresponding suggestion.

## Permissions

- `storage`: saves your profile names, URLs, and aliases locally.
- `contextMenus`: supports a browser context-menu action for requesting LinkVault suggestions.
- `<all_urls>` host access: allows LinkVault to detect matching fields on websites. Browser restrictions and your site-access settings may limit where it can run.

## Your choices

You can edit or delete saved profiles in LinkVault. You can also remove the extension through your browser's extension settings; browser-managed local extension data may then be removed by the browser.

## Changes to this policy

This policy may be updated when LinkVault's functionality or data practices change. The latest version will be published at this page.

## Contact

For privacy questions, contact the publisher through the support contact shown on the LinkVault Chrome Web Store listing.
