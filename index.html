Install LinkVault

LinkVault is distributed from GitHub. Chrome and Brave support manual installation of unpacked extensions.

1
Download and extract

Download the ZIP and extract the folder on your computer.

2
Open extensions

Visit chrome://extensions in Chrome or brave://extensions in Brave.

3
Enable Developer mode

Turn on Developer mode using the switch on the extensions page.

4
Load unpacked

Choose “Load unpacked” and select the extracted folder containing manifest.json.

Note: GitHub distribution requires manual installation. LinkVault is not currently listed in the Chrome Web Store.

Simple by design. You stay in control.

LinkVault stores your profile names, URLs, and aliases locally. It does not store passwords or submit forms. You choose when a suggested URL is inserted into a field.
